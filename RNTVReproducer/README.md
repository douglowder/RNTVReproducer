# React Native TV : Demo / Reproducer App

Demonstrating an issue on Android TV physical device, that a focused item does not receive focus again after navigating back from a screen, as it should. Apple TV works as expected.

### NOTE / UPDATE: 

- This DOES work on an Android TV emulator. (Running Android TV OS 13)

- Not working on physical Android TV box. Running Android TV OS 13. 
(* I'm not sure you can even buy Android 16 TV boxes yet)
